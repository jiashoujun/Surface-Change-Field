# Surface-Change-Tensor
Rigid and Non-Rigid Surface Change Tensors for Topographic Dynamics Monitoring

This project is providing Supplementary Material of our constribution to ISPRS Congress 2026. 

Supplementary Material A gives more comprehensive details on change estimation results with different parameters on real-world datasets. 

Supplementary Material B gives visualisation results of only significant (rigid and non-rigid) changes in forms of accumulative and incremental.
